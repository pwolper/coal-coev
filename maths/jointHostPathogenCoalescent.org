* Introduction
Phylodynamic inference of disease dyamics relies on connecting epidemiological dynamical models to a coalescent model of a sample of genetic sequences, often done heuristically. In order for the pathogen tree to relate to the host-measured SI process this typically employes several assumptions: (i) host evolution occurs on a much slower time scale (i.e. is neglegible) than the epidemic and (ii) each host is only infected with one pathogen individual. If these are given then we can construct the pathogen coalescent from $N_{\text{pathogen}} \sim I$.
 
In real world host-pathogen systems though these assumptions can often be violated due to reciprocal host-pathogen interactions, complex disease-life cycles, including varying transmission modes, vectors and environmental factors. Importantly, evolutionary time scales of host and pathogens likely play a role in all but the most explosive epidemics.
Many diseases have the ability to pass from infected to offspring through vertical transmission, in addition to horizontal epidemic infection dynamics. As infected hosts act as vessels for pathogens, it follows that the pathogen coalescent trees are embedded into a host genealogy, determined through vertical and horizontal transmission dynamics. The behaviour of joint host-pathogen genealogical processes is not well understood, limited to approaches by [[cite:&welch-2005-integ-geneal-epidem]], as to our knowledge there is no generalized coalescent model based on the reproductive processes of hosts and pathogens, and the infection process that connects them ([[cite:&ebert-2020-host]]).

** Vertical pathogen transmission through host generations
The host population reproduces in discrete generations and non-overlapping generation, following a Wright-Fisher process of size $N$. At the end of each generation $n$, there are $X_n$ hosts infected. We transition to the next generation by host reproduction, during which infected host have the probability $c_v$ to pass the pathogen on to their offspring, infecting vertically.  At the beginning of each generation $n+1$ there are $I_{n+1}$ infected host offspring, that are the founding individuals for the epidemiological process. 

** Epidemic pathogen dynamics within host generations
Alternating host reproduction, we have a continuous epidemiological process within each generation, representing horizontal transmission of infectious disease. This process runs for time $G$, which describes the length of the epidemic phase between host reproduction, and is well suited to describe seasonal epidemics for example in plants. Depending on the length of $G$, we can also adjust the relative speed of evolution of hosts to pathogens (for later?).

In the following, we describe the horizontal epidemiological process $\mathcal{J}_t$ pathogen during host generations $n+1$ as an SI infection model with contact rate $\beta$, occuring for time $G$. For more details and derivation of the model see notes 'SI_coalV3.pdf'.

\begin{equation}
\mathcal{J}_t: \quad J_0  \rightarrow J_G \quad \text{at rate } \beta(N-J_t)J_t/N.
\end{equation}

with intital conditions $\mathcal{J}_0 = I_n+1$ as the number of infected host offspring. The fraction of infected hosts $i(t) = J_t/N$ follows the the ODE

\begin{equation}
\frac{di}{dt} = \beta i(1-i), \quad \text{with } i(0) = J_0/N
\end{equation}

that has the solution

\begin{equation}
i(t) = \frac{i_0}{e^{-\beta t}(1-i_0) + i_0}.
\end{equation}

For one intial infection this system looks like the following: with the number of infected growing faster in time depending on the transmission rate $\beta$.

** Deterministic equilibrium of the number of infected hosts
Assuming the number of infected at the end of the generation $n+1$ to be

\begin{equation}
X_{n+1} = I_{n+1} + K_{n+1}
\end{equation}

where $I_{n+1}$ is the number of infected host offspring and $K_{n+1}$ individuals are newly infected due to the epidemiological process $\mathcal{J}_G$ in generation $n+1$.

If we take $N$ to infinity, we get the deterministic limit of the model, and with $x_n = X_n/N$ we have $I_{n+1}/N \approx c_v x_n$. See notes for further details. For the stationary solution $x_n = x_{n+1} = x$ we get

\begin{equation}
x = x^* = \frac{c_v - e^{-\beta G}}{c_v(1-e^{-\beta G})} 
\end{equation}

The value of $x^*$ for values of $c_v$, $\beta$ and $G$ are shown below. Values of $x^* < 0$ are set to 0, as biologically, we require a positive fraction $x$.

We wish to understand the boundary conditions for pathogen extinction, as the non-trivial equilibrium above can yield $x^* < 0$, which is un-meanigful, as $x = X / N \in [0,1]$. The value of $x^*$ is positive for all positive values of the numerator, as the denominator is positive for all $c_v$, $\beta$ and $G$ greater than 0. As the numerator is positive under $c_v > (1-c_v)e^{-\beta G}$, we get the boundary condition for persistence of the pathogen as

$$c_v > \frac{1}{1+e^{\beta G}}$$

As $\beta G \ge 0$, the r.h.s is always smaller than or equal $0.5$, which means that $c_v > 0.5$ guarantees the equivalence to be true; this amount of vertical transmission is always enough for the deterministic persistence of the pathogen, regardless of how low the horizontal transmission $\beta G$ drops. By the same logic, if the vertical contact rate $c_v < 0.5$, we get the minimum horizontal transmission $\beta G$ required to avoid extinction as

$$\beta G > \ln \left(\frac{1-c_v}{c_v}\right)$$ 

As the rate of vertical transmission $c_v\rightarrow 0$ the, r.h.s grows to $\infty$, which makes sense, as no amount of horizontal transmission can overcome lack of transmission between generations.

In strict absence of vertical transmission the pathogen tracks the $N$ hosts coalescent tree with a number of infected $X = x^{*0}/N = \left(\frac{2c_v -1}{c^2_v}\right)N$, as a function of the probability of vertical transmission.

** Pairwise coalescent probability
The probability that two randomly sampled pathogen lineages coalesce depends on both hoizontal and vertical transmission. Coalescence can happen either within an epidemic clade deriving from each founding offspring infected (with probability $\pi$) or following host coalescence with vertical transmission in both host infected offspring. In the later case the probability is $1/N$, such that

$$p_c = P(\text{coalescence of two pathogen lineages with one host generation}) = \pi + (1-\pi)\frac{1}{N}.$$

Following the derivation of $\pi$ from a Pólya urn model (see appendix), we obtain
$$\pi = \frac{j}{j+I-1}\frac{2}{I+1}$$.

Expecting $I = Nc_v x^*$ founding infected and $j = Nx^* - I = N(1-c_v)x^*$ newly infecteds, such that in leading order (?)

$$\pi = \frac{N(1-c_v)x^*}{N x^* - 1} \frac{2}{c_v x^* N + 1} \approx \frac{2(1-c_v)}{c_v x^*}\frac{1}{N}$$

the coalescence probability becomes
 
$$p_c\approx \frac{1}{N}\left(1+\frac{2(1-c_v)}{c_vx^*}\right), $$

which become finally after substituting eqn for $x^*$:

$$p_c\approx \frac{1}{N}\left[1+\frac{2(1-c_v)\left[1-(1-c_v)e^{-\beta G}\right]}{c_v-(1-c_v)e^{-\beta G}}\right]$$

*** Ancestral process $A_n$
Ancestral process $A_n$ denotes the number of pathogen lineages $n$ generations backwards in time, decreating whenever two lineages coalesce. Suppose you start with $k$ pathogen samples at the present generation, the number of lineages starts  $A_0=k$, and goes through the process $k \rightarrow k-1 \rightarrow k-2 \rightarrow \cdots \rightarrow2 \rightarrow1$. If $N$ is large that higher order terms disappear $p_c = \mathcal{O}(N^{-1}) << 1$, the ancestral process can be defined as 

$$P(A_{n+1}=A_n-1\mid A_n) = p_c {A_n\choose2}$$

gives you the transition probability of the lineage-counting process, from that, you can construct the entire ancestral process:

$$ n \xrightarrow{\lambda_n} n-1 \xrightarrow{\lambda_{n-1}} n-2 \rightarrow \cdots \xrightarrow{\lambda_2} 1.$$

where $\lambda_k$ is the coalescence rate when there are $k$ ancestral lineages.
Suppose there are currently $k$ ancestral lineages. There are ${k\choose2}$ possible pairs, and each pair coalesces with probability $p_c$. Probability of a coalescent event when there are $k$ lineages

$$\lambda_k = p_c {k\choose 2} = p_c\frac{k(k-1)}{2}$$

with waiting times $T_k$ until the next coalescence approximately geometric (?) distributed in continuous time ($A_n = A_t$) following $P(T_k=t\mid A=k) = (1-\lambda_k)^{t-1}\lambda_k$ with $t=1,2, \ldots$, and an expected value of

$$E[T_k] = \frac{1}{\lambda_k} = \frac{2}{p_c k(k-1)}.$$

Define $T_{n}$ as the time backwards to the most recent common ancestor of $n$ samples, where $T_k$ is the waiting time distribution for the process to go from $k$ lineages to $k-1$. The expectation $E[T_n]$ derives from summing over all $T_k$ down to $k=1$ lineage. For a large sample size $n$, we get the following [fn:: where the final equality follows from $\frac{1}{k(k-1)}=\frac{1}{k-1}-\frac{1}{k}$]:

\begin{align}
E[T_{n}] &= \sum_{k=2}^n E[T_k] = \frac{2}{p_c}\sum_{k=2}^n\frac{1}{k(k-1)} = \frac{2}{p_c} \left(1-\frac1n\right).
\end{align}

For large $n$, this approaches $E[T_{n}]\approx 2/p_c$.

* Stochastic simulations
** SLiM Two-Species semi-discrete WF-SI 
The above model is implemented as a individual-based, stochastic model with hosts and parasite species in SLiM (using two species in a non-WF framework). The host species reproduces in discrete, non-overlapping WF generations every $G+1$ ticks, while in between host reproduction events, the stochastic infection model runs, following an SI process. Thus $G$ represents the timescale of the host to pathogen reproductive processes, and determines the relative length of the epidemic relative to the host reproduction.
Host reproducing following WF dynamics can pass pathogens on to their offspring if infected as vertical transmission with probability $c_v$. We implement the epidemiological model as a stochastic, individual-based model as follows below:

Each host individual makes contact with another host individual at rate $\beta$, thus the waiting time between an individuals contacts is $\tau \sim \text{Exp}(\beta)$ and the number of contacts a host makes in a time interval of $t$ is distributed $C \sim \text{Poisson}(\beta \Delta t)$. For $J_t$ independent infected hosts, the number of contacts made by the infected individuals within one tick of interval ($\Delta t = 1$), follows:

$$C_t = \sum_{j=1}^{J_t} C_j \sim \text{Poisson}(\beta J_t)$$

and the effective contacts where infection can happen (as only the contacts with a susecptible host) can be written as

$$C_{\text{eff}} \sim \text{Poisson}\left(\frac{\beta J_t (N-J_t)}{N}\right)$$

In our simulation for each tick we draw the number of effective contacts, sample $C_\text{eff}$ the infecting individuals and target hosts with replacement. To not allow susceptibles to be contacted twice in one tick (they can only be infected once), we keep only the first contact, removing duplicates. We then add a horizontally transmitted pathogen as a clone of the infecting indvidual.

*Comparison of stochastic SI model to deterministic version.* 
We derive the stochastic infectious process, and show it behaves similar to the deterministic version above under small $\beta$.
Following the total effective number of contacts $C_\text{eff}$, distributing the number of contacts uniformly over $S = N - J_t$ susceptible host results in the per susceptible contacts $C_k \sim \text{Poisson}((\beta J_t)/N)$, for each susceptible host $k$. From this distribution, the probability to become infected is defined as

$$p = P(C_k > 0) = 1 - e^{\beta J_t/N}$$

Thus for each step time, there are $\Delta J$ infected hosts with.

$$\Delta J \sim \text{Binomial}\!\left(N-J,\; 1-e^{-\beta J/N}\right), \qquad E[\Delta J]=(N-J)\left(1-e^{-\beta J/N}\right).$$

The number of infected after each time step is $J_{t+1} = J_t + \Delta J$, 

$$J_{t+1} = J_t + (N - J_t)(1-e^{-\beta J_t /N})$$

which for $i = J/N$ becomes

$$ i_{t+1} = i_t + (1 - i_t)(1-e^{-\beta i_t})$$

Comparing this to the deterministic ODE $i' = \beta i(1-i)$, which for $\Delta t << 1$ we can rewrite in discrete form as

$$i_{t+1} = i_t + (1-i_t) \beta i_t $$

We see, that the deterministic and stochastic models differ by $\beta i_t \ge 1- e^{-\beta i_t}$, and that the stochastic version grows slower than the deterministic one, due to the possibility of a susceptible individual being hit by multiple infections, but we only count the first one. For $\beta i << 1$, this has little effect.
